# CareerFlow OS — Overview

**What it is:** an AI-assisted job-search command center. Track applications on a Kanban board,
manage interviews like a CRM (with stages, company research, and a calendar), keep CVs and notes,
get notifications and email-driven automation, and use AI (your own key or rule-based fallback) to
score and tailor your CV and prep for interviews. Local-first, free to run, self-hostable on one VPS.

**Status:** complete across all planned phases. 59 unit tests, clean build + lint, full e2e smoke green.

---

## What's built (by area)

### Core (free, no AI required)
- **Auth & multi-user** — email/password (NextAuth, JWT sessions). Public marketing page at `/`;
  app behind login.
- **Job tracker** — Kanban board (`/board`) with drag-and-drop across Wishlist → Applied →
  Interview → Offer → Rejected; companies; per-job detail.
- **Interview workspace** (job page) — a **stage stepper** (Applied → Screening → Technical →
  Onsite → Final → Offer), an interview **timeline grouped by stage**, notes, and CV tagging.
- **Calendar** (`/calendar`) — month grid + upcoming interviews.
- **CV manager** (`/cvs`) — multiple versions (upload or paste), set default, tag CV→job.
- **Dashboard** (`/dashboard`) — applications, response rate, offers, interviews-this-week, pipeline.
- **Home** (`/home`, post-login) — this-week interviews, action nudges, inbox suggestions,
  quick stats, quick-add, recent activity.

### AI layer (optional — BYO key, with rule-based fallback)
- **Provider-agnostic router** — Claude / OpenAI / Groq / Gemini / Ollama via your own keys
  (`/settings`); rule-based fallback so everything works with **no key**.
- **Features** — CV **match score** + missing keywords, **CV tailoring**, **interview prep**,
  **career chat** (`/assistant`), **company research** brief.

### Notifications (`/notifications`)
- Header bell + feed. Event-driven (status/stage changes) inline; time-based interview reminders
  (24h + 1h) and nudges generated by `POST /api/internal/run-notifications` (run on a schedule).
- External ingest `POST /api/internal/notify` for automation (e.g. recruiter replies).

### Automation (n8n — self-hosted, free, optional)
- App "brain" endpoint `POST /api/internal/process-email` classifies an email
  (interview/rejection/offer), matches it to a job, and **proposes** a status change you confirm
  on `/home` (never auto-changes data).
- n8n runs from `docker-compose.n8n.yml`; example workflows in `n8n/` (Gmail monitor + reminders
  schedule). See [`../n8n/README.md`](../n8n/README.md).

### Billing (`/billing`) — scaffold, no payments yet
- Free vs **Pro** plans with entitlements (managed AI, advanced analytics, unlimited limits).
- Free caps (50 jobs / 5 CVs) → friendly 402 upgrade prompts. Pro-gated CV-performance analytics.
- Upgrade is **simulated** (flips the plan); the checkout handler is the seam for real Stripe later.

## Architecture

Single **Next.js 14** (App Router) app: React UI + API routes + service layer (`src/services/*`,
all scoped to a `userId`) over **Prisma** + **PostgreSQL**. AI is a provider-router with adapters.
Machine-to-machine endpoints live under `/api/internal/*` and are guarded by `INTERNAL_API_SECRET`
(not session). n8n is a separate optional container.

```
src/
  app/            # pages + API routes (incl. /api/internal/* for cron/automation)
  services/       # business logic (job, interview, cv, note, stats, nudge, notification,
                  #   suggestion, plan, email/*, ai/*) — userId-scoped, unit-tested
  components/     # React UI
  lib/            # db, auth helpers, constants, entitlements, internal-auth
prisma/           # schema + migrations + seed
n8n/              # example workflows + README
docs/             # specs, plans, DEPLOY.md, this file
```

## How to run (local)

Requires Node 22, Docker, and (on Windows) WSL.

```bash
docker compose up -d            # local Postgres (port 5433, isolated project)
npm install
npx prisma migrate dev          # apply migrations
npm run db:seed                 # demo account + sample data
npm run dev                     # http://localhost:3000
```

Demo login: **demo@careerflow.local** / **password** — or sign up at `/signup`.
`.env` needs `DATABASE_URL`, `AUTH_SECRET`, `AUTH_TRUST_HOST`, `INTERNAL_API_SECRET`.

### Tests

```bash
npm test        # Vitest — services + AI router + email + plan (run sequentially; share one DB)
npm run build   # type-checks everything
npm run lint
```

### Optional: automation

```bash
docker compose -f docker-compose.n8n.yml up -d   # n8n at http://localhost:5678
```
Or simulate an email without Gmail (see [`../n8n/README.md`](../n8n/README.md)):
```bash
curl -X POST http://localhost:3000/api/internal/process-email \
  -H 'x-internal-secret: dev-internal-secret' -H 'Content-Type: application/json' \
  -d '{"userId":"local-user","from":"recruiter@acme.com","subject":"Interview at Acme Corp","body":"schedule a call"}'
```
